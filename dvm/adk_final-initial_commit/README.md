
# ADK POC

This is a proof-of-concept project for the ADK (Agent Development Kit).

## Running the application

To run the application, you need to have Python 3.12 or higher installed.

1.  Install the dependencies:

    ```bash
    uv pip install -r pyproject.toml
    ```

2.  Run the application:

    ```bash
    python src/adkpoc/main.py
    ```

    The application will be available at `http://127.0.0.1:8081`.
